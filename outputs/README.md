# FinLearn AI — Outputs Directory

This directory contains all numerical evaluation tables, cross-validation logs, feature importances, and high-resolution visualization charts generated by the ML valuation pipeline.

---

## 📁 Directory Structure

```
outputs/
├── tables/     # Numerical evaluation CSV tables & prediction logs
└── charts/     # High-resolution PNG publication figures & EDA plots
```

## 📈 2. Charts (`outputs/charts/`)

| File | Description |
|---|---|
| `model_comparison.png` | Bar chart comparing Test Accuracy, Balanced Accuracy, Weighted F1, and Macro F1 across all models. |

| `eda_histograms.png` | Feature histograms demonstrating positive skewness in valuation multiples. |
| `eda_pairplot.png` | Multivariate pairwise scatter relationships across key ratios (P/E, P/B, ROE, ROCE, Debt/Equity). |
| `feature_importance_xgboost.png` | Horizontal bar plot of XGBoost feature importances. |
| `feature_importance_randomforest.png` | Horizontal bar plot of Random Forest feature importances. |
| `feature_importance_adaboost.png` | Horizontal bar plot of AdaBoost feature importances. |
| `eda_outlier_summary.csv` | Numerical table of lower and upper IQR bounds, min, max, and outlier counts per feature. |
